# Product Overview

Agent Evaluation is a generative AI-powered framework for testing virtual agents. It uses an LLM agent (evaluator) to orchestrate multi-turn conversations with target agents and evaluate their responses.

## Key Capabilities

- Simulates concurrent, multi-turn conversations with agents
- Built-in support for AWS services (Amazon Bedrock, Amazon Q Business, Amazon SageMaker)
- Custom agent integration via extensible target system
- Hook system for integration testing and additional tasks
- CI/CD pipeline integration for automated agent testing

## Target Users

Developers building and testing conversational AI agents, particularly those using AWS services.
